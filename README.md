# PRODIGY_ML_02 — Customer Segmentation Using K-Means

## Internship
- **Organization:** Prodigy InfoTech
- **Track:** Machine Learning
- **Task:** Task 02

## Objective
To implement K-Means clustering to group mall customers based on annual income and spending score.

## Dataset
Mall Customer Segmentation Data from Kaggle:

https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Methodology
1. Loaded and explored the customer dataset.
2. Checked missing values and duplicate records.
3. Selected annual income and spending score as features.
4. Standardized the features using StandardScaler.
5. Used the Elbow Method to examine the number of clusters.
6. Applied K-Means clustering with five clusters.
7. Visualized customer segments and analyzed the cluster summary.

## Results
The model grouped customers into five segments with different income and spending patterns. The project demonstrates how unsupervised machine learning can support customer segmentation.
